# Visualisation

The visualisation group contains the tools to look at your data. At present it
has a single command, an interactive viewer that shows volumes as orthogonal
slices in a common world space, which makes it useful for checking the inputs
and the results of the other commands.

| Command           | Summary                                                              |
| ----------------- | -------------------------------------------------------------------- |
| [`view`](view.md) | Interactive viewer showing one or more volumes as three orthogonal slice views. |

The viewer relies on Matplotlib, an optional dependency; see
[Requirements](view.md#requirements).
